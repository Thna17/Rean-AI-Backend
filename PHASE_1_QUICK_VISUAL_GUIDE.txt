  1. Open app → See problem list (filtered by subject/difficulty)
  2. Select problem → AI teaches step-by-step on whiteboard
  3. Complete problem → Mark as easy/medium/hard
  4. See schedule → "Review in 3 days"
  5. Come back later → Problem due, review it
  6. Repeat → Build learning journey over time
