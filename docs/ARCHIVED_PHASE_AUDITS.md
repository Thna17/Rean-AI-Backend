# Historical phase and audit material

The root-level `PHASE_*`, `AUDIT_*`, `VISUAL_TUTOR_*`, `START_*`, `READY_FOR_*`, and similar completion/hand-off files are retained as historical working material. They may describe earlier layouts such as `flutter-app`, `backend-service`, `admin-service`, or `mcp-server`; those paths are obsolete.

They are not the source of truth for current operation, deployment, or release decisions. Use these documents instead:

- `ARCHITECTURE.md`
- `LOCAL_DEVELOPMENT.md`
- `RELEASE_RUNBOOK.md`
- `KNOWN_LIMITATIONS.md`

No historical user material was deleted as part of this documentation cleanup.
