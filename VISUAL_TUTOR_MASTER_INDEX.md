## 🎓 Key Concepts (Quick Reference)

### Teaching Patterns
- **Math**: Problem → Visualize → Question → Discover → Verify
- **Physics**: Scenario → FBD → Apply laws → Calculate → Verify with graphs
- **Chemistry**: Molecular → Electrons → Energy → Reaction → Observable

### Teaching Approach
- NOT ChatGPT (passive reading)
- Like real teacher (active dialogue)
- Socratic method (questions first, answers later)
- Visual progression (simple → complex)
- Student interaction (required at each step)

### Rich Media
- Graphs (Plotly)
- Diagrams (Canvas)
- Animations (Rive)
- 3D molecules (optional, later)
- Interactive elements (student draws/manipulates)

### Technology Stack
```
Frontend: Flutter + Dart
  ├─ Plotly.dart (graphs)
  ├─ Canvas (shapes, vectors)
  └─ Rive (animations)

Backend: Python + FastAPI
  ├─ Pydantic (models)
  ├─ MongoDB (persistence)
  └─ LLM (subject experts)

Curriculum: JSON
  ├─ Cambodia MOE standards
  ├─ Topics & concepts
  └─ Problem examples
```

## 🎬 The Vision (One Paragraph)

You're building an **AI Visual Tutor** that feels like a **real teacher with a whiteboard**, not like ChatGPT. For Cambodia Grade 10-12 students in Math, Physics, and Chemistry, the tutor will show problems visually (graphs, diagrams, animations), ask guiding questions, wait for student responses, and adapt based on understanding. The interaction is collaborative discovery, not passive explanation. Success means students say **"I figured it out!"** not **"I watched someone solve it."**
